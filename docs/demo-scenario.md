# 시연 시나리오 — "호우경보 + 항구 침수 + 강풍·풍랑"

앱 **프로필 → 시연 모드**를 켜면 상황판·지도·길찾기·AI가 모두 같은 시연 데이터를 쓴다 (2026-10-07).

- 센서 위치·대피소·산사태 지도는 **실제 데이터**, 측정값만 시연 값이다 (`server/risk/demo.py`). 판정 규칙은 실측과 같다.
- DB에 저장하지 않는다. 실제 사용자 알림, 실측 화면, AI 장기 기억에는 영향이 없다.
- 위험 영역 받기 `GET /api/v1/demo/risk/areas`, 경로 `POST /api/route {"demo": true}`, AI `POST /api/chat {"demo": true}`

## AI에게 물어볼 질문

같은 위치에서 시연 모드를 켜고 묻는다. 답은 근거(시연 측정값)만 쓰고, 경로는 지도에서 볼 수 있다.
2026-10-07 VM(https://34-64-177-195.nip.io) 확인 7/7 통과, 재시도 0 (답 10~16초). 같은 질문도 매번 문장이 조금씩 다르다.

| --- | --- | --- |
| 1 항구 | 지금 여기 침수 위험 있어? | 침수 경보 영역 안, 환승센터 수위계 230mm(22m 거리), 호우 경보 → 구룡포중학교 앞 1187m |
| 1 항구 | 어디로 대피해야 해? | 구룡포중학교 앞 1187m·15분, 더 가까운 세 곳은 위험 영역 안이라 제외했다고 설명 |

## 주의

- 산사태 경고가 산지 대부분(위험지도 1등급 100m 범위, 50km²)을 덮는다. 시가지 길찾기에서도
  "지나는 위험 구역: 산사태 경고"가 자주 뜬다 (사용자 결정 2026-10-07: 위험지도 데이터 유지).
- 대피소·길찾기 판단은 **주의 이상**만 쓴다. 지도의 "보통" 원은 표시만.
- 경로 서버는 위험 영역을 60초 캐시한다 — `demo.py`를 바꾼 뒤 1분 뒤에 확인.
- 장면 값 다시 재기: 로컬에서 `docker compose up -d` 후 각 장면 좌표로 `POST localhost:8002/api/route {"demo": true, "strategy": ...}`.
  센서 값을 바꿀 때 지킬 것은 `server/tests/test_demo_scenario.py`.
